# Morgan_Stanley_Team_15

Demo site for Love 21 foundation

## Live Site

https://hammerhead-os.github.io/Morgan_Stanley_Team_15/

## What you can try

1. **Home**: Short video intro with different roles to select
2. **About**: Scrolly telling about mission and educating people
3. **Family**: Register for classes and manage household profiles
4. **Contributor**: Place to hire people and volunteer for short tasks
5. **Just Curious**: For people who want a quick glance
6. **Profile**: To manage calendar, tasks, etc
