What is loaded now

every panel and export reads from these tables

Expected columns (extra columns are kept and shown too)

Activities
  • Activity ID · Name
  • Category — e.g. Sports, Wellness, Education
  • Group — e.g. Basketball, Yoga, Cooking
  • Date Start Time End Time
  • Location
  • Participants Volunteers Staff — names separated by ;
  • Attended Absent Cancelled — names separated by ;, for sessions that already ran
A recurring activity is one row per date, so each session keeps its own roster and its own attendance record. Anyone on the roster but in none of the three lists shows as “not recorded”. You can also set attendance by hand — open a past session and click the badge next to a name.
Enrollments (optional long format)
  • Activity ID
  • Person or Name
  • Role — participant / volunteer / staff
  • Attended — yes/no, present/absent, 1/0, or cancelled
  • Date (optional, targets one session)
Use this instead of the semicolon lists if your source system exports one row per sign-up.
People
  • Person ID · Name
  • Role — admin / volunteer / participant
  • Email Phone Address
  • Date of Birth or Age
  • Joined · Last Online
  • Emergency Contact Notes
90+ days since Last Online marks the person Inactive automatically. Attendance (365 days) and hours are calculated from the activity rosters — you don't supply them.
Donations
  • Donation ID
  • Campaign / Drive — e.g. "Donate 10 running shoes!"
  • Donor (name) or Person ID
  • Amount · Date · Time
  • Method Note
Visitors
  • Date
  • User Type — parent/carer, individual volunteer, corporate volunteer, corporation/NGO, general visitor
  • Age Group or Age
  • Visits (optional count; defaults to 1 per row)
  • Source Region

Hours are earned, not uploaded. Marking someone present at a past session banks that session's length — End Time minus Start Time — as volunteer hours (volunteers) or participation hours (participants). No-shows, same-day cancellations and sessions without times bank nothing, and staff monitoring a session are not counted. The Attendance (365d) and Hours (365d) columns are a rolling window over the last 365 days; the profile pop-up also shows all-time hours.

Dates are read as YYYY-MM-DD when possible; slash dates are read month-first unless the first number is above 12. Everything you load stays in this browser (nothing is uploaded anywhere) and is restored the next time you open the file.
